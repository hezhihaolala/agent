# 归源 · 家族记忆助手产品设计文档

## 1. 产品定位

归源是一款面向家庭族谱管理员的中文 Web 应用，用于整理家族成员、亲属关系、照片文献和口述资料，并通过智能体帮助用户查询关系、补充信息和发现待核实内容。

产品采用“自研主流程、复用成熟开源组件”的方向：界面、数据模型和智能体交互围绕中文家庭场景自行设计；族谱可视化、文件处理和模型接入等基础能力优先复用成熟方案，不直接套用复杂的传统族谱系统。

核心原则：

- 数据可信：重要信息应标注来源和核实状态。
- 回答可追溯：智能体回答应展示关系路径和引用资料。
- 修改可控制：智能体只能生成变更草稿，管理员确认后才写入。
- 默认私密：家族资料不公开，模型密钥和敏感操作均由服务端管理。

## 2. 目标用户与使用场景

MVP 只服务一名家族管理员。典型场景包括：

- 录入家族成员及父母、子女、配偶关系。
- 浏览多代族谱，快速定位某位成员。
- 归档家谱原件、老照片和口述记录，并关联相关人物。
- 用自然语言询问亲属关系、人物经历或资料缺口。
- 让智能体整理一段资料，在确认后更新族谱。

## 3. 主要功能

### 3.1 家族概览

展示成员数量、世代数量、资料数量、待核实事项和近期更新，作为管理员进入系统后的工作台。

### 3.2 族谱与人物档案

- 以树状结构浏览家族成员和代际关系。
- 支持查看、创建和编辑人物档案。
- MVP 先支持父母、子女和配偶三类核心关系。
- 人物基础字段包括姓名、性别、出生与去世信息、籍贯、简介和核实状态。

### 3.3 资料档案

- 上传图片、PDF 和文字记录。
- 记录资料名称、类型、年代、来源和备注。
- 将资料关联到一个或多个人物，作为智能体回答和信息核实的依据。

MVP 不追求全自动识别；扫描件可先由管理员手动填写摘要，OCR 和批量导入后续再做。

### 3.4 归源智能体

- 亲属关系问答：回答两人关系并展示推导路径。
- 人物与家族资料问答：基于已录入内容回答，并列出引用来源。
- 辅助录入：把管理员的自然语言整理成结构化人物或关系草稿。
- 待核实提醒：指出缺失、冲突或来源不足的信息。

智能体不得直接修改正式数据。所有新增和修改都进入“变更预览”，由管理员核对后确认或退回。

### 3.5 设置与维护

- 单管理员登录与密码管理。
- OpenAI 兼容 API 的地址、模型和密钥配置。
- 数据备份、恢复和基础操作记录。

## 4. 核心操作流程

### 4.1 录入成员

管理员手动填写或输入一段自然语言 → 系统生成结构化草稿 → 检查人物重名和关系冲突 → 展示变更预览 → 管理员确认 → 写入并记录操作日志。

### 4.2 查询关系

管理员提出问题 → 系统识别人名和查询意图 → 从正式族谱数据计算关系路径 → 结合关联资料生成回答 → 展示结论、路径和来源。

### 4.3 整理资料

管理员上传资料 → 填写基础信息和摘要 → 关联人物 → 标记可信度或待核实状态 → 资料进入可检索范围。

## 5. MVP 范围

第一版需要完成：

- 单管理员登录。
- 人物与核心亲属关系的增删改查。
- 可浏览的基础族谱树。
- 图片、PDF 和文字资料归档及人物关联。
- 基于正式数据的亲属关系问答和来源展示。
- 智能体生成变更草稿、管理员确认写入。
- 基础操作日志和数据备份。
- Linux VPS 上通过 Docker Compose 部署。

第一版暂不包含：

- 多用户协作和复杂权限体系。
- 公开家族主页或社交功能。
- 全自动 OCR、照片识人和大规模批量导入。
- 原生手机应用。
- 复杂图数据库和多智能体工作流。

## 6. 技术与部署方向

- 前端继续采用 React、TypeScript，保持独立中文 Web 体验。
- 后端提供统一 API，负责身份验证、族谱数据、档案、智能体工具调用和操作日志。
- MVP 使用关系型数据库保存人物和关系，不额外引入图数据库。
- 文件保存在受控存储目录中，数据库只保存元数据和关联信息。
- 模型通过托管的 OpenAI 兼容 API 接入，API 密钥不下发到浏览器。
- 使用 Docker Compose 编排 Web、后端和数据库，优先保证一台 Linux VPS 可简单部署和备份。

## 7. 迭代顺序

1. 数据基础：登录、人物、关系、族谱树和备份。
2. 资料能力：上传、归档、人物关联和来源标记。
3. 智能体能力：关系问答、引用来源和确认式写入。
4. 增强能力：OCR、GEDCOM 导入导出、多人协作和更丰富的家族叙事。

## 8. MVP 成功标准

- 管理员能独立建立并维护一份真实的小型族谱。
- 常见直系和姻亲关系能够被正确查询并展示路径。
- 智能体回答能够说明依据，不把不确定信息当作事实。
- 任何智能体写入都必须经过明确确认，并可通过日志追踪。
- 新服务器可按照文档完成部署、备份和恢复。
